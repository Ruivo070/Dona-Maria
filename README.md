# Restaurante Dona Maria Betim

Site de página única feito com HTML, CSS e JavaScript puros. Os arquivos principais ficam na raiz; a pasta `dona-maria-betim/public` contém a cópia preparada para publicação.

## Testar localmente

Abra `index.html` no navegador. Não é necessário instalar dependências. Fontes, fotos temporárias e mapa precisam de conexão com a internet.

## Publicar no Render

1. Envie a pasta do projeto para um repositório Git.
2. No Render, escolha **New + → Blueprint** e conecte o repositório.
3. O arquivo `render.yaml` publica `dona-maria-betim/public`; não há etapa de build.
4. Após a publicação, substitua `URL-DO-SITE.onrender.com` pela URL gerada nos metadados de `index.html`, em `robots.txt` e em `sitemap.xml`.
5. Se atualizar os arquivos principais, copie a versão atualizada para `dona-maria-betim/public` antes de publicar.

## Revisão de conteúdo

Os preços são referências e os horários de jantar têm divulgações diferentes. Consulte a equipe para atualizar essas informações e substitua as imagens temporárias por fotos autorizadas do restaurante.
