# Dona Maria Betim — publicação

Site estático feito com HTML, CSS e JavaScript. Os arquivos principais ficam na pasta acima; `public/` contém a cópia enviada ao serviço de hospedagem. A pasta `docs/` reúne os documentos escolares.

## Testar no computador

Abra `../index.html` no navegador ou use a extensão Live Server no VS Code.

## Publicar no Render

1. Envie o projeto para um repositório Git.
2. No Render, crie um **Static Site** conectado ao repositório.
3. Use `public` como diretório publicado e deixe o comando de build vazio.
4. Se atualizar os arquivos principais, copie a versão atual para `public/` antes de publicar.
5. Depois da publicação, substitua `URL-DO-SITE.onrender.com` pela URL gerada nos metadados, em `robots.txt` e em `sitemap.xml`.

## Revisão antes de publicar

Confira os preços e horários com a equipe e substitua as imagens temporárias por fotos autorizadas do restaurante.
